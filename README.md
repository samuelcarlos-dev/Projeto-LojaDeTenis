# Y2k.sneakers

## Projeto de Loja Virtual de Tênis

Projeto desenvolvido no curso Técnico em Desenvolvimento de Sistemas, com foco no planejamento, experiência do usuário (UX), estruturação de interfaces e preparação para implementação Front-End.

---

## Sobre o Projeto

A Y2k.sneakers é uma proposta de loja virtual de tênis voltada para usuários interessados em calçados esportivos, moda urbana e modelos de diferentes marcas.

O projeto foi desenvolvido inicialmente a partir do levantamento de requisitos, definição do escopo, planejamento da experiência do usuário, criação de wireframes, definição da identidade visual e organização dos recursos necessários para a futura implementação do sistema.

---

## Objetivo

Criar uma interface de e-commerce de tênis que permita ao usuário:

- visualizar produtos;
- consultar informações dos produtos;
- navegar entre as diferentes áreas da loja;
- acessar detalhes de produtos;
- utilizar recursos de navegação e interação;
- encontrar formas de contato com a loja.

---

## Público-Alvo

O projeto é direcionado principalmente para:

- Jovens entre 14 e 35 anos;
- Pessoas interessadas em tênis;
- Pessoas interessadas em moda urbana e produtos esportivos.

---

## Escopo

O escopo inicial do projeto contempla:

- Página inicial;
- Catálogo de produtos;
- Página de detalhes do produto;
- Navegação entre páginas;
- Carrossel de conteúdo;
- Destaques de marcas;
- Exibição de produtos;
- Informações dos produtos;
- Formas de contato no rodapé;
- Identidade visual própria;
- Organização dos assets;
- Estrutura preparada para implementação Front-End.

---

## Páginas do Projeto

### 1. Home

A Home apresenta a identidade da loja e concentra os principais elementos de entrada do usuário.

#### Principais elementos

- Campo/ícone de busca;
- Logo da Y2k.sneakers;
- Carrinho;
- Login;
- Carrossel principal;
- Destaques de marcas;
- Produtos em destaque;
- Rodapé.

---

### 2. Produtos

A página de produtos apresenta o catálogo da loja em formato de grade.

#### Principais elementos

- Cabeçalho;
- Navegação;
- Filtros;
- Ordenação;
- Grid de produtos;
- Imagens dos produtos;
- Nome;
- Preço;
- Acesso aos detalhes do produto;
- Rodapé.

---

### 3. Detalhes do Produto

A página de detalhes apresenta informações específicas sobre um produto selecionado no catálogo.

Essa página complementa o fluxo de navegação do catálogo, permitindo que o usuário saia da listagem e consulte individualmente um produto.

---

### 4. Contato

O projeto não utiliza uma página independente de contato.

As formas de contato são disponibilizadas diretamente no rodapé da interface, mantendo o acesso às informações de contato disponível durante a navegação.

## Estrutura Semântica Planejada

A estrutura das páginas foi planejada considerando a organização semântica dos elementos HTML.

A estrutura geral prevista é:

```text
Header
 ├── Busca
 ├── Logo
 ├── Carrinho
 └── Login

Main
 ├── Conteúdo principal
 ├── Produtos
 └── Componentes específicos da página

Footer
 ├── Informações da loja
 ├── Redes sociais
 ├── Links
 └── Formas de contato
 ```text
