# Projeto NovaWeb Studio

Repositório inicial estruturado durante o treinamento de versionamento.

## Requisitos do Sistema

-Git instalado

-Editor de código (VS code)

-Sistema operacional Windowns

## Escopo

### Tema 
-Loja virtual de tênis
### Objetivo
-Criar um sistema que permite aos usuários conhecer os produtos, visualizar seus detalhes e entrar em contato com a loja.
### Público-alvo
- Jovens entre 14 e 35 anos;
- Pessoas interessadas em tênis

## Páginas do projeto
1. HOME

-Função:
- Apresentar a loja

-Conteúdo:
- Logo;
- Menu de navegação; 
- Banner principal;
- Produtos em destaque;
- Rodapé.
2. PRODUTOS

-Função:
- Mostrar todos os produtos.

-conteúdo:
- Menu;
- Lista de produtos em cards;
- Imagem;
- Nome;
- Preço;
- Botão "ver mais".
3. CONTATO

-Função:
- Permitir contato com a impresa.

-Conteúdo:
- Menu;
- Informações da loja;
- Formulário
    - Nome
    - E-mail
    - mensagem
- Botão Enviar

## Requisitos Funcionais
- O usuário deve conseguir navegar entre todas as páginas.
- O site deve exibir uma lista de produtos.
- O usuário deve visualizar informações dos produtos.
- O usuário deve preencher um formulário de contato.
- O menu deve estar disponível em todas as páginas

## Requisitos Não Funcionais
- Interface simples e intuitiva.
- carregamento rápido.
- Layout respondivo. 
- Organização padronizados do código.
- Compatibilidade com navegadores modernos.
