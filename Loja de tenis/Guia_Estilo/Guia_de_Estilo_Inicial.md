# Guia de Estilo Inicial — Y2k.sneakers

## 1. Identidade Visual

A Y2k.sneakers é uma loja virtual de tênis com uma identidade visual inspirada na estética urbana e contemporânea, buscando transmitir personalidade, modernidade e destaque visual para os produtos.

A identidade visual será aplicada de maneira consistente nas páginas do projeto, mantendo padrões de cores, tipografia, imagens, botões e demais componentes da interface.

## 4. Hierarquia Visual

A interface utilizará diferentes tamanhos e pesos tipográficos para estabelecer uma hierarquia clara entre:

- Títulos;
- Subtítulos;
- Nomes dos produtos;
- Preços;
- Informações complementares;
- Botões e chamadas para ação.

---

## 5. Aplicação da Identidade Visual

A identidade visual deverá ser mantida de maneira consistente entre as diferentes páginas do projeto:

- Home;
- Produtos;
- Detalhes do produto.

Os elementos de navegação, cabeçalho e rodapé também deverão manter padrões visuais consistentes.

---

## 6. Regra 60-30-10

A regra 60-30-10 será utilizada como referência para equilibrar a distribuição das cores:

- 60% — cor dominante;
- 30% — cor secundária;
- 10% — cor de destaque.

A aplicação dessa proporção não precisa ser matematicamente exata em cada elemento da interface. Ela funciona como uma referência visual para evitar excesso de cores e preservar a hierarquia da interface.

---

## 7. Objetivo Visual

O objetivo da identidade visual é criar uma interface:

- moderna;
- organizada;
- consistente;
- visualmente reconhecível;
- adequada ao público interessado em tênis e moda urbana.
